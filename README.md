# SMK 10 SMARTSCHOOL Backend

Express.js API lokal tanpa SQL/database. Data disimpan sebagai file JSON di `src/data`.

## Endpoint
- GET /api/health
- GET /api/prestasi
- GET /api/fasilitas
- GET /api/ekstrakulikuler

## Menjalankan
```bash
npm install
npm run dev
```
Backend berjalan di http://localhost:4000.
